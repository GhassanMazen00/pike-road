# Downloads for milestone 1 (sounds)

These need a free Freesound login, so you download them. Everything else is already in the project.

**How:** open the link, press play, and if it sounds right, sign in and click **Download**.
Rename the file to the name in the **Save as** column (keep its own extension: `.wav`, `.mp3` or `.ogg`)
and put it in the folder shown. The game picks it up the next time you run it. No editing needed.

The links are **candidates I picked by title and license (CC0)**. I can't listen to them, so trust your ears.
If none fit, use the search link in that row. All searches are already filtered to CC0.
If you pick a sound that is not CC0, tell me its author so I can credit it.

**Tips**
- One sound per file. If a download has an open *and* a close in it, send it to me and I'll split it.
- Looping sounds (room tone, clock) work best as `.ogg` or `.mp3`. A `.wav` also works, with a tiny gap at the loop point.
- Creaks: anything in the `creaks` folder plays at random every 14 to 40 seconds from around the house.
